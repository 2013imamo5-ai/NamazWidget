# NamazWidget — виджет времени намаза

Android-виджет с четырьмя размерами: **4×1, 2×2, 4×2 и 4×3**. Расписание на 12 месяцев перенесено из фотографий бумажного календаря. Обеденный намаз — **12:15 ежедневно**. Интернет, геолокация и фоновые сервисы не нужны.

## В версии 1.1.0

- Живой секундный обратный отсчёт до следующего намаза, в том числе до утреннего намаза следующего дня.
- Подсветка следующего намаза.
- Полупрозрачный стеклянный фон и настройки прозрачности.
- Смена даты и расписания, плановые обновления границ молитв и восстановление после перезагрузки.
- Фиксированные четыре размера виджетов.

Таймер отображается системным Android **Chronometer**: секунды обновляются системой, без перерисовки bitmap каждую секунду. Обновление подсветки на границе намаза может быть отложено Android при энергосбережении.

## APK и безопасная подпись

**Важное ограничение v1.0:** первая сборка была подписана временным debug-ключом GitHub Actions. Прежний закрытый ключ не сохранён. Поэтому для перехода на v1.1.0 необходима **однократная переустановка**: удалить старую версию, установить v1.1.0 и добавить виджеты снова. Это ограничение Android; сам пользовательский APK не может менять свою подпись.

Для v1.1.0 создан постоянный EC P-256 ключ. Он хранится в публичном репозитории **только в зашифрованном виде** в `signing/namaz-release.p12.enc.b64`. Чтобы GitHub Actions публиковал подписанные APK с тем же постоянным ключом, владелец репозитория должен один раз добавить секрет:

1. Откройте `Settings → Secrets and variables → Actions → New repository secret` в данном репозитории.
2. Имя: `NAMAZ_SIGNING_PASSPHRASE`.
3. Значение: переданный вам приватно пароль расшифровки.
4. Затем откройте `Actions → Build APK → Run workflow`.

При наличии секрета workflow расшифрует ключ только в runner, подпишет релиз и создаст GitHub Release с файлом **NamazWidget.apk**. Для скачивания будет доступен прямой адрес:

https://github.com/2013imamo5-ai/NamazWidget/releases/latest/download/NamazWidget.apk

**Не публикуйте пароль/секрет в коде, issues или README!** При утрате пароля зашифрованный ключ будет невозможно восстановить. Не выкладывайте незашифрованный `.p12`.

## Точность расписания

Ряд цифр на оригинальных фотографиях читается неуверенно, поэтому расписание следует сверить с бумажным календарём перед использованием. Неразборчивые значения обозначены прочерком; вычисления по местоположению не используются.
