# NamazWidget

Android home-screen prayer times widget with four sizes (4×1, 2×2, 4×2, 4×3), translucent green glass background and configurable opacity.

The day-by-day schedule is transcribed from the supplied paper calendar and is being verified against the photos; days not yet included are displayed as unavailable, never estimated.

Build with GitHub Actions → Build APK; download the artifact named `NamazWidget-debug-apk`.
